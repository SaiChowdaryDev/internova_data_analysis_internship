# Week 3 – SQL & Excel for Data Analytics

## Overview

This week focuses on SQL and Microsoft Excel skills used in Data Analytics.

## Objectives

- Retrieve and analyze data using SQL
- Filter, sort and group data
- Use SQL aggregate functions
- Perform SQL Joins and Subqueries
- Work with Excel data
- Apply formatting, sorting and filtering
- Use Excel functions for analysis
- Use VLOOKUP and XLOOKUP
- Create Pivot Tables and Charts
