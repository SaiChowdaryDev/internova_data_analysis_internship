# Task 2 - Data Cleaning & Preparation

## Objective

To inspect and prepare the imported datasets using Power Query in Power BI.

## Work Done

- Opened Power Query Editor.
- Inspected the Sales, Products and Customers tables.
- Checked the column names and data types.
- Set Order_Date as Date type.
- Set numeric columns such as Quantity, Sales and Unit_Price as Whole Number.
- Checked the datasets for missing or blank values.
- Checked Order_ID for duplicate records.
- Verified that the data was clean and suitable for analysis.
- Applied the changes using Close & Apply.

## Data Types

### Sales
- Order_ID - Whole Number
- Order_Date - Date
- Product_ID - Text
- Customer_ID - Text
- Region - Text
- Category - Text
- Quantity - Whole Number
- Sales - Whole Number

### Products
- Product_ID - Text
- Product_Name - Text
- Category - Text
- Unit_Price - Whole Number

### Customers
- Customer_ID - Text
- Customer_Name - Text
- Segment - Text
- Region - Text

## Conclusion

The datasets were inspected and prepared using Power Query. The required data types were verified, missing values and duplicates were checked, and the cleaned data was loaded back into Power BI for further analysis.
