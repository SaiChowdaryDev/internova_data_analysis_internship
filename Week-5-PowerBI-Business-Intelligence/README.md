# Week 5 - Power BI & Business Intelligence

## Objective

The objective of this week is to learn the basics of Power BI and Business Intelligence. 
The tasks include importing and cleaning data, creating relationships between tables, 
using DAX measures, creating visualizations and building an interactive dashboard.

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- CSV datasets

## Dataset

The project uses sales-related data consisting of three tables:

1. Sales - Contains order and sales transaction details.
2. Products - Contains product information and prices.
3. Customers - Contains customer and customer segment information.

## Tasks Completed

### Task 1 - Power BI Introduction & Data Import
Imported Sales, Products and Customers datasets into Power BI and checked the tables, columns and data types.

### Task 2 - Data Cleaning & Preparation
Used Power Query to inspect the data, check missing values, duplicates and correct data types.

### Task 3 - Data Modeling & Relationships
Created relationships between Sales, Products and Customers tables using common ID columns.

### Task 4 - DAX Calculated Columns & Measures
Created DAX measures to calculate total sales, total orders, average order value, maximum sales and minimum sales.

### Task 5 - Power BI Visualizations
Created different charts and visuals such as bar charts, column charts, line charts, donut charts, tables and KPI cards.

### Task 6 - Interactive Dashboard
Created an interactive sales dashboard using KPI cards, charts and slicers for filtering the data.

### Task 7 - Business Insights & Recommendations
Analyzed the dashboard to identify important sales trends, high-performing categories and regions, and provided business recommendations.
