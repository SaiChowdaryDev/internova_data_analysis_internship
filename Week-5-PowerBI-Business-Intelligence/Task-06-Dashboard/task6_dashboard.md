# Task 6 - Interactive Dashboard & Filters

## Objective

To create an interactive sales dashboard using Power BI.

## Dashboard Components

### KPI Cards
- Total Sales
- Total Orders
- Average Order Value

### Visualizations
- Sales by Category
- Sales by Region
- Sales Trend Over Time
- Sales Distribution by Category
- Sales Details Table

### Filters
- Region
- Category

## Work Done

An interactive dashboard was created using multiple Power BI visuals, KPI cards and slicers. The slicers allow the user to filter the dashboard based on region and category.

## Conclusion

The interactive dashboard provides a simple view of sales performance and allows users to explore the data using filters.
