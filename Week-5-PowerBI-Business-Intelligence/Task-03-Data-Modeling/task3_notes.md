# Task 3 - Data Modeling & Relationships

## Objective

To create relationships between the Sales, Products and Customers tables.

## Relationships Created

- Sales[Product_ID] → Products[Product_ID]
- Sales[Customer_ID] → Customers[Customer_ID]

Both relationships use Many-to-One cardinality.

## Work Done

- Opened Model View in Power BI.
- Connected the Sales table with the Products table using Product_ID.
- Connected the Sales table with the Customers table using Customer_ID.
- Verified the relationships between the tables.
- Created a basic data model for analysis.

## Conclusion

The required relationships were created successfully between the tables. The data model can now be used for DAX calculations and visualizations.
