This week focuses on applying basic statistics, data visualization, and Exploratory Data Analysis using Python.

- Task 2 – Variance & Standard Deviation

- Task 5 – Matplotlib Visualization
- Task 6 – Seaborn Visualization
- Task 7 – EDA – Data Inspection & Cleaning
- Task 8 – EDA – Correlation & Insights

- Python

Student performance data is used for the analysis.

Through these tasks, I practiced calculating statistics, creating visualizations, cleaning data, identifying relationships and outliers, and presenting data-driven insights and recommendations.
